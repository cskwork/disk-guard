How the lifecycle works from leak to reclaim.

No background daemon polling CPU every second. disk-guard hooks directly into the native OS scheduler and runs a deterministic four-stage sweep.

  1. 1.0 · ACCUMULATION

    Browsers and build tools leak multi-gigabyte clones into per-user temp directories.

    On macOS, Google Chrome and Electron apps duplicate full application bundles inside DARWIN_USER_DIR/X/*.code_sign_clone during background signature verification. On Windows, headless sessions leave scoped_dir* and chrome_BITS_* directories in %TEMP%. When processes crash or exit uncleanly, the OS never reclaims them until a full reboot. 

    $ getconf DARWIN_USER_DIR
/var/folders/xx/.../0/
# Stale bundles accumulate under ../X/*.code_sign_clone and ../T/XcodeDistPipeline.*
  2. 2.0 · REGISTRATION

    One script registers a native user-space schedule without root privileges.

    Running ./install.sh on macOS writes `~/.local/bin/disk-guard.sh` and bootstraps a user `LaunchAgent` (`com.disk-guard.agent`). Running `install.ps1` on Windows copies `disk-guard.ps1` to `%LOCALAPPDATA%\disk-guard` and registers `DiskGuard-Daily` and `DiskGuard-Logon` via `schtasks.exe`. 

    Installed disk-guard:
  Script:   ~/.local/bin/disk-guard.sh
  Schedule: ~/Library/LaunchAgents/com.disk-guard.agent.plist (daily at 04:00 + on login)
  Log:      ~/Library/Logs/disk-guard.log
  3. 3.0 · DRY-RUN AUDIT

    Preview every candidate path before deleting a single byte.

    Pass --dry-run on macOS or -DryRun on Windows to list every directory that exceeds its age threshold without modifying the filesystem. All user directories (`$USER`, `$USERNAME`, `DARWIN_USER_DIR`, `%TEMP%`) are resolved dynamically at runtime. 

    $ ~/.local/bin/disk-guard.sh --dry-run
[2026-10-17 04:00:00] disk-guard start (user: dev, dry-run: 1, free: 64Gi)
  [dry-run] delete /var/folders/.../X/com.google.Chrome.code_sign_clone/Clone_98a1
  [dry-run] delete /var/folders/.../T/XcodeDistPipeline.812a
[2026-10-17 04:00:01] disk-guard done  (free: 64Gi)
  4. 4.0 · SCHEDULED PURGE

    Age-gated pruning keeps active sessions untouched and logs reclaimed space.

    Only directories older than their respective TTL (`180` minutes for code-sign clones, `1` day for build pipelines, `3` days for test artifacts) are removed, ensuring running browser sessions and active test suites are never interrupted. 

    [2026-10-17 04:00:00] disk-guard start (user: dev, dry-run: 0, free: 64Gi)
[2026-10-17 04:00:03] disk-guard done  (free: 88Gi)

Cross-platform cleanup specification.

Every target directory is matched against modification time before deletion. Custom directories can be appended via DISK_GUARD_EXTRA_PATHS.

Category macOS Path Pattern Windows Path Pattern Default TTL
Chromium & Electron Clones $DARWIN_USER_DIR/X/*.code_sign_clone/* %TEMP%\scoped_dir*, chrome_BITS_* 180 minutes
Build & Browser Pipelines $DARWIN_USER_DIR/T/XcodeDistPipeline.*, scoped_dir* %TEMP%\playwright*, puppeteer_dev_chrome_profile-* 1 day
Test & Profiling Artifacts $DARWIN_USER_DIR/C/com.apple.dt.Instruments, T/pytest-of-$USER %TEMP%\pytest-of-%USERNAME% 3 days
Agent Visualization Caches ~/.codex/visualizations/* %USERPROFILE%\.codex\visualizations\* 3 days

Runtime flags and environment overrides.

Tune retention windows per machine using CLI flags or environment variables without editing the script.

Environment Variable macOS Flag Windows Flag Default

DISK_GUARD_ARTIFACT_TTL_DAYS --artifact-ttl-days N -ArtifactTtlDays N 3
DISK_GUARD_EXTRA_PATHS colon-separated (:) semicolon-separated (;) empty
